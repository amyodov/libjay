// --- the infinite levels of L: and S: --------------------------------------
// `_` is the whole argument, however deeply it is boxed: there is nothing
// to descend into and nothing to collect, so both spellings and both
// valences are the operand applied to what they were given. `__` is the
// other end — the leaves, which is level 0 written the other way round.

// --- the binomial below its diagonal ---------------------------------------
// `x ! y` is zero wherever a whole y sits under a whole x: the falling
// factorial meets a zero factor there. Past the width at which that product
// is taken, the gamma quotient stands in and reads a pole over a pole as no
// value at all, which is what these lines hold it to. The other two shapes
// that quotient cannot reach are named rather than answered and are not
// here: a NEGATIVE whole y under such an x (`100000000 ! _2` is 100000001
// there) and a fractional y under one (`1e10 ! 2.5` is _1.05786e_35), both
// of which need the logarithms of the gamma function rather than its
// values.
