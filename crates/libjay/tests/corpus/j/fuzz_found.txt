// Reshape lays out ITEMS, not elements: the result's shape is the left
// argument followed by the shape of an item, so a rank-2 right argument
// keeps its rows. libjay reshaped the ravel, which is APL's rule.
6 $ i. 2 3
$ 6 $ i. 2 3
$ 3 $ i. 3 4
3 $ i. 3 4
$ 2 3 $ i. 3 4

2 3 $ i. 6
4 $ 1 2 3

// An empty left argument asks for no axes at all, whatever type it
// carries, and the answer is the first item.
'' $ 5
'' $ i. 3 4
$ '' $ i. 3 4
'' $ (<i. 2 2);5
// An empty right argument is refused only when the result needs an item.
2 3 $ i. 0
2 3 $ ''
3 $ 0 3 $ 0
$ 2 3 $ i. 0 0

// The outfix over an argument shorter than the width leaves out no run at

$ _2 +/\\. i. 0

// Equality is total: a character and a number, or a box and a number, are
// unequal rather than a type error. Ordering still has a domain.
'a' = 1
'abc' = 1 2 3
'a' ~: 1
(<1) = 1
(1;2) = 1 2
(<1) = <1
0 = <'abc'
(i. 2 3 4) ~: 1;2 3
(2 7 1 8) ~:"_1 'a'
a: ~: 3 3 $ 1 0 0 0 1 0 0 0 1

'a' e. 1 2

// A scalar fret marks every item, so `1 u;.2 y` is one interval per item.

0 <;.1 i. 3

// `x /: y` is `(/: y) { x`, so the two lengths need not agree: a shorter
// key selects fewer items, and only an index past the end of x is wrong.

1 2 3 /: 'ab'
2.0 4.0 6.0 \\: 'a'
2 {. 2.0 4.0 6.0 \\: 'a'

// An empty operand has no element for a scalar verb to run on, so its type

// A count of zero on an axis after the first empties that axis; it is not
