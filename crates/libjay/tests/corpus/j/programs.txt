// Programs rather than sentences.
//
// Every line here is a whole program: several assignments feeding one
// another, a defined verb or two, control flow where the program wants it,
// and a final value small enough to read. The rest of the corpus asks what
// one primitive does; this theme asks what happens when twenty of them are
// asked to cooperate — a name bound in one sentence and read in the next, a
// verb defined and then applied under rank, a matrix built and then reduced.
//
// The final value is deliberately modest. Intermediates are as large as the
// program needs; what gets recorded is a short vector, so a diff of this
// snapshot is readable and a change of answer names itself.
//
// Where floats are unavoidable the program rounds them into integers before
// the last sentence, so the recorded answer is exact rather than merely
// within tolerance.
