// Wave 6: naming an adverb or a conjunction, the dyadic level and spread,
// and the hypergeometric series.

// Naming a modifier. The name is that modifier from the next sentence on,
// so the sentence around it parses exactly as the glyph would.
m =. /\n+ m 1 2 3
m =. /\n* m 1 2 3 4
m =. /\n>./ m 1 2 3
a =. ~\n+ a 3
a =. ~\n2 - a 5
c =. @\n(+/ c *:) 1 2 3
c =. @:\n(+/ c *:) 1 2 3
c =. &\n2 (+ c *:) 3
c =. ^:\n(>: c 3) 5
m =. /\nmean =. + m % #\nmean 1 2 3 4
m =: /\n+ m 1 2 3
// A name can change part of speech: the noun wins from there on.
m =. /\nm =. 5\nm + 1
// A modifier name inside a definition body is the modifier there too.
m =. /\nf =. 3 : '+ m y'\nf 1 2 3

// The dyadic level and spread: both arguments are descended together, and
// a side that has reached its level is held while the other descends.
(1;2) ,L:0 (3;4)
