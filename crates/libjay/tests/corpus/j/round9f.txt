// Round 9F: a NaN through comparison, ordering and the set verbs, and the
// GCD at the edge of the machine word.
//
// One mechanism runs through the whole first half. The reference has two
// comparison loops. Its TOLERANT loop asks whether a difference EXCEEDS
// the tolerance and builds every non-strict test out of the negation of a
// strict one, so a NaN — which fails every strict test — is equal to
// everything it is set against, is never less or greater than anything,
// and never wins a min or a max. Its EXACT loop is machine equality,
// where a NaN equals nothing at all, not even itself. Which loop runs is
// settled by the operands and never by their values: an integer, boolean
// or complex operand is exact at every length, an extended or rational
// one tolerant at every length, and two floats are exact over ONE pair
// and tolerant over more.
