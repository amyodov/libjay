// The obverse table: what undoes each verb.
//
// Three spellings read it — `u b. _1` names the obverse, `u^:_1` applies
// it, and `u&.v` runs u under v — so every row here is asked at least
// twice: once for the name where the reference and libjay spell the answer
// the same way, and once on data.
//
// `u b. _1` answers a SPELLING, and libjay writes its own: a derived verb
// whose operand is a noun is `(n&+)` here where the reference writes the
// noun out. Only the rows the two spell alike are asked by name; the rest
// are asked with `^:_1` and `&.`, which compare values.
