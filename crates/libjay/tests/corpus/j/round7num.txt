// Round 7B: the numeric rules measured against jconsole — the prime
// queries over a y that is not whole, the prime count and its bound, the
// binomial at its own argument, and the logarithm of an exact 1.
//
// NOT HERE, DELIBERATELY: `q:` of a complex number and `3 p: _.`. The
// reference answers each with nothing at all — no value, no shape, no type
// — which is the signature of the silent `q: _.` death the quarantine list
// carries. Neither may be recorded.

// THE PRIME COUNT. `p:^:_1 y` is `_1 p: y`: how many primes stand strictly
// below y, which for a prime y is that prime's own index.
p:^:_1 ] 0

p:^:_1 ] 2

p:^:_1 ] 10

p:^:_1 (2 3 $ i. 6)
3!:0 (p:^:_1 (i. 10))
p: ^:_2 ] 10
_1 p: 100
_1 p: 1000000

// Its argument need not be whole: the count below y is the count below its

p:^:_1 ] 4.1

// THE LOGARITHM OF AN EXACT 1 is an exact 0, and 1 is the only argument
// whose natural logarithm keeps the extended type. The rational type
// declines with the rest of the transcendentals.
^. 1x
3!:0 (^. 1x)
^. (1x 1x 1x)
3!:0 (^. (1x 1x 1x))

3!:0 (^. (1x 2x))

3!:0 (^. 2x)
3!:0 (^ 0x)
^ ^:_1 ] 1x
3!:0 (^ ^:_1 ] 1x)
3!:0 (^ ^:_1 (1x 1x))

// `_2 x:` IS `%/"1`, THE ALTERNATING QUOTIENT over the last axis — the
// obverse of form 2, which splits each value into a numerator and a
// denominator along a new last axis. The division is the ordinary one, so
// the exact types survive it and a complex pair divides as complex. An axis
// with nothing along it folds to the identity 1; an axis of ONE item is
// that item, never divided, which is why a lone character or box comes back
// untouched where a table of them is refused.
_2 x: (1 2 3)
3!:0 (_2 x: (1 2 3))
$ _2 x: (1 2 3)
_2 x: (i. 2 3)
$ _2 x: (i. 2 3)
_2 x: (i. 2 3 4)
_2 x: (1 2 3x)
_2 x: (1.5 2.5)

_2 x: (3j4)
_2 x: (, 5)

_2 x: (2 0 $ 0)
_2 x: (2 1 $ 5)
_2 x: (2 3 $ 'abcdef')
_1 x: (1 2 3)
