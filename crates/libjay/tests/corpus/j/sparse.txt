// Sparse arrays: `$.` as a storage kind. J only — APL has no sparse form.
//
// The monad converts a dense array; the dyad's left argument names a form,
// which either converts between the two storage kinds, builds a new sparse
// array from a shape, or asks about one. The display is a line per stored
// entry: its position along the sparse axes, `|`, then what it holds.

// The monad: every axis sparse, zero the sparse element, and the entries in
// ravel order.
$. 0 0 3 0 5
$ $. 0 0 3 0 5
3!:0 $. 0 0 3 0 5
$. 1 2 3
$. 0 0 0
$. i. 2 3
$. 3 4 $ 0 0 1 0 0 2 0 0 0 0 0 3
$. 2 2 2 $ 0 0 0 7 0 0 0 9
$. 0 _12 0 345 0

// The element type comes through, and the type code is the dense one a
// thousand and twenty-four times over. The boolean cases are computed
// rather than written down: jconsole narrows a 0/1 LITERAL to boolean
// storage where libjay keeps integers, a divergence of its own that this
// theme has no reason to restate.
$. 1 0 1 0
$. (1 0 1 0 = 1)
3!:0 $. (1 0 1 0 = 1)
$. 0 1.5 0 0 _2.25
3!:0 $. 0 1.5 0 0 _2.25
$. 0 3j4 0 1j_2
3!:0 $. 0 3j4 0 1j_2
$. 0 0.5 0 _2 0 1000

// A scalar has no axis to store along and stays dense; an empty array keeps
// its shape and stores nothing.

$. < 1 2
$ $. i. 0

$ $. 0 3 $ 0
$. 0 3 $ 0

// A sparse array is the array it stands for: it matches the dense one, and
// the verbs that ask about its shape rather than its elements answer as
// they would for that.

// own rank is.
