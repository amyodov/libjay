// AN INSERT'S IDENTITY CARRIES NO TYPE OF ITS OWN under the scan: the
// identity stands for a run that was never made, and the ARGUMENT'S type
// stands instead. `3!:0 (<./\ (0 $ 1x))` is 64 there, not the 8 the

// THE EXACT TYPES ARE CLOSED UNDER THE MATRIX PRODUCT. `%` divides the
// exact types exactly and the machine integers into floats, and the inner
// product follows it: `3!:0 ((1 2x) +/ . * (1 2))` is the extended type
// there and a product of two rational matrices the rational one, where a
// blocked float pass answers eight. One exact side is enough.
