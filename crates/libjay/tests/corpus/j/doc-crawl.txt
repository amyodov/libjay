// The documentation crawl: the J Dictionary read entry by entry, every
// documented behavior class turned into a sentence, and every sentence put
// to the oracle.
//
// The file is organised the way the Dictionary index is — `=` first, the
// alphabetic entries (`a.` through `x:`) last — so a reader who wants to
// know what the crawl asked of one primitive can find it by its spelling.
// What it collects is the EDGES: the empty argument, the length-zero axis,
// the infinity and the NaN in a position that usually holds a count, the
// exact types (extended, rational, complex, symbol) where a float would
// have been easier, and the rank a primitive is documented to have rather
// than the rank its common use implies. The middle of each primitive's
// domain is already covered by `arithmetic`, `structural` and the rest;
// nothing here repeats it on purpose.
//
// Sentences whose answer is not a function of the sentence — the rolls and
// the deals — are here only as their shape. Where the crawl found libjay
// and the oracle disagreeing, the sentence is NOT here: it is a ticket, and
// it earns its corpus line when it is fixed.
