// The capped fork and the representation of an explicit definition.
//
// `[: f g` and `f@:g` are one function and two spellings, and the tree
// keeps which was written, so a verb gives back the spelling it was made
// with. An explicit definition is the `:` conjunction over its valence and
// its body, which is what `5!:1`, `5!:2` and `5!:5` write it out as
// whichever way the source spelled it — inline, on the lines below, or
// between a pair of braces.

// --- the capped fork writes itself back out -----------------------------

f =. [: +: *:\nf
f =. [: +: *:\n5!:5 <'f'
f =. [: +: *:\n5!:1 <'f'
f =. [: +: *:\n5!:2 <'f'
f =. [: +: *:\n5!:6 <'f'
f =. +:@:*:\nf
f =. +:@:*:\n5!:1 <'f'
f =. +:@:*:\n5!:2 <'f'
f =. [: +: [: *: -:\nf
f =. [: +: [: *: -:\n5!:1 <'f'
f =. [: +: [: *: -:\n5!:2 <'f'
f =. [: +: *:@-:\nf
f =. [: +: *:@-:\n5!:1 <'f'
f =. [: +/ ,\nf
f =. [: <. %\nf
f =. ] ,~ [: i. #\nf
f =. ([: +: *:)^:_1\nf
f =. ([: +: *:)"0\nf
f =. ([: +: *:)"0\n5!:1 <'f'
f =. [: +: *: :. -:\nf
f =. [: +: *: :. -:\n5!:1 <'f'
g =. ([: +: *:)`(+:@:*:)\ng
g =. ([: +: *:)`(+:@:*:)\n> 0 { g
