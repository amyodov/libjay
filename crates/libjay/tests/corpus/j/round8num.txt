// Round 8B: the complex floor and the complex residue, measured against
// jconsole point by point.
//
// McDonnell's floor puts the Gaussian integer below y where the fractional
// parts of the two components fall inside the unit triangle, and steps one
// place along the larger of them otherwise. BOTH of its comparisons read
// the comparison tolerance in force, and the reference reads them
// differently: the triangle test is TOLERANT and the tie between the two
// fractional parts is EXACT. `9!:19 ] 0` and `<.!.0` each put the tolerant
// one back to an exact comparison, which is how it was identified.
//
// The residue is `y - x * <. y % x`, and the quotient inside it is the
// textbook conjugate formula rather than the scaled division `%` itself
// uses. The two part on a knife edge — a quotient exactly at a half in
// both components — and on overflow.

// --- the complex floor inside the unit triangle -------------------------
<. 0.3j0.3
<. 0.01j0.01

<. 3.5j4.5
<. 1.5j2.5
<. _0.5j3.5
<. _2.5j_2.5
<. 2.5j_1.5
<. 0.99j0.99
<. 0.7j0.3
<. 0.3j0.7

// --- the tie between the fractional parts is EXACT ----------------------
// Both parts a half: the real step, every time.
<. 0.5j0.5
<. 1.5j1.5
<. _0.5j_0.5
<. _3.5j0.5
<. 2.5j2.5
// A part one ulp under the other, still an exact comparison: the smaller
// one loses, and the answer moves.
<. 0.49999999999999j0.5
<. 0.5j0.49999999999999
<. 0.5000001j0.5
<. 0.5j0.5000001

// --- the triangle test is TOLERANT --------------------------------------
// The two fractional parts sum to just under one; the tolerance reads that
// sum as one, so the value is outside the triangle and the floor steps.
<. 0.3j0.69999999999999
<. 0.7j0.29999999999999
<. 0.9j0.09999999999999
// Far enough under, and it is inside again.
<. 0.3j0.6999999999
<. 0.7j0.2999999999
// The fit spells the tolerance out. With none at all the sum is below one
// and nothing steps.
<.!.0 (0.49999999999999j0.5)
<.!.0 (0.3j0.69999999999999)
<.!.0 (0.5j0.5)

// --- the ceiling is the floor reflected through the origin --------------
>. 0.5j0.5
>. 0.3j0.3
>. _0.5j3.5
>. 0.49999999999999j0.5
>. 3j4
>. 1.5j2.5
>.!.0 (0.49999999999999j0.5)

// --- the two verbs that MAKE a complex number refuse what is not a number -
// They reached an internal error over data of no numeric type; the answer is
// the type error every other arithmetic verb gives. An argument with NO
// elements never gets there: it is read as a boolean empty first.
