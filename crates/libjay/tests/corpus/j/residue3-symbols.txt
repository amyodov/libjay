// `s:` in full: the forward forms that write an array of symbols out as
// text, the negative ones that read the same text back, and what each of
// them does to a shape, a type and an argument of the wrong kind. The four
// forms that report the interpreter's own table — `0`, `6`, `7` and `_6` —
// are in divergences.txt instead, with the reason they cannot agree.
//
// A symbol ATOM's format is damaged in the reference (see decisions.md,
// 2026-09-12), so every display here is of a LIST, of the boxes `5 s:`
// makes, or of a shape.

// The monad, which is the three negative forms chosen by what it is handed.

// `1 s:` and `2 s:`: the raze with a separator before each name and after

// `3 s:` and `4 s:`: one row per symbol, padded to the longest with a null
// and with a blank. The two forms differ in the pad and in nothing else.

$ (3 s: (s: '`a`bcd'))
a. i. (4 s: (s: '`a`bcd'))

a. i. (4 s: (s: '`abc`def'))

$ (3 s: (0 $ s: 'x'))

$ (3 s: (0 3 $ s: 'x'))
$ (4 s: (s: (2 2 3 $ 'abcdefghijkl')))
a. i. (4 s: (s: (2 2 3 $ 'abcdefghijkl')))

// `5 s:`: one box per symbol, the argument's own shape.

// Two symbols made from the same text are the same atom, whichever form
// made them.
