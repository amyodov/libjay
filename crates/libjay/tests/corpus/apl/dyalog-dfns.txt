// Dfn features Dyalog defines and GNU APL has no reading of at all: a
// guard `cond:expr`, `⍺←` as a default for a missing left argument, `∇` as
// the dfn's own name, the shy result of a trailing assignment, and the
// lexical scope an inner dfn sees. GNU APL cannot parse any of these — its
// dfns have no guards, no `∇`, and assign `⍺←` unconditionally — so there
// is no `gnu:` column here and nothing to hold libjay to. The file is
// recorded ground truth for the Dyalog dialect, and the replay counts the
// lines libjay does not match yet rather than failing on them.
//
// Every line is one sentence; `⋄` separates the statements of a dfn body
// exactly as it separates top-level ones. Results are kept small and exact.
@ reference=dyalog
