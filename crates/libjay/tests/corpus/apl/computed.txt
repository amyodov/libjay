// Operands the program computes: a `⍣` count, an `f[k]` axis, the axis a
// `∇` header binds and a `{…}` reads as `χ`, and the one assignment that
// writes through a bracket standing inside a larger sentence.
//
// What these have in common is that the derived function cannot be built
// while the program compiles: the count or the axis is read where the
// function is applied, in the names the application can see.
//
// A definition is fixed and its answer assigned away (`Q←…`) where the
// sentence would otherwise have a value of its own: a GNU APL session
// displays every sentence it runs and libjay answers with the last one.

// --- ⍣ over a count the program computes ---------------------------------
N←3 ⋄ ⌽⍣N⊢1 2 3
N←2 ⋄ ⌽⍣N⊢1 2 3
N←0 ⋄ ⌽⍣N⊢1 2 3
⌽⍣(1+1)⊢1 2 3
⌽⍣(1+2)⊢1 2 3
N←1 ⋄ ⌽⍣(N+1)⊢1 2 3
N←1 ⋄ ⌽⍣(N+2)⊢1 2 3
N←3 ⋄ 1+⍣N⊢0
N←3 ⋄ ⍴+⍣N⊢5
N←2 ⋄ 2×⍣N⊢1
N←4 ⋄ 2×⍣N⊢1
N←3 ⋄ F←{⍵+1} ⋄ F⍣N⊢0
F←{⍵+1} ⋄ F⍣(2+3)⊢0
N←2 ⋄ ⍴⌽⍣N⊢2 3⍴⍳6
// The operand of an operator is one token's worth, so the `+1` here
// belongs to the sentence and not to the count.
N←2 ⋄ ⌽⍣N+1⊢1 2 3
// A count read from a definition's own argument, which is the whole
// point of reading it late.
∇Z←R N\nZ←⌽⍣N⊢1 2 3\n∇\nR 1
∇Z←R N\nZ←⌽⍣N⊢1 2 3\n∇\nR 2
∇Z←R N\nZ←⌽⍣N⊢1 2 3\n∇\nR 3
F←{⌽⍣⍵⊢1 2 3} ⋄ F 1
F←{⌽⍣⍵⊢1 2 3} ⋄ F 2
F←{2×⍣⍵⊢1} ⋄ F 5

// --- f[k] over an axis the program computes ------------------------------
M←2 3⍴⍳6 ⋄ K←1 ⋄ +/[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ +/[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ +⌿[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ ⌽[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ ⌽[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ ⊖[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ ,[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ ⍴,[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ +\\[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ +\\[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ ×/[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ ⌈/[K]M
M←2 3⍴⍳6 ⋄ +/[2-1]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ +/[K-1]M
M←2 3⍴⍳6 ⋄ K←0 ⋄ +/[K+1]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ 1↑[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ 2↑[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ 1↓[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ ⊂[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ ⍴⊂[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ 1 0/[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ 1 0 1/[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ M,[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ M,[K]M
M←2 3⍴⍳6 ⋄ K←1 ⋄ 10 20 30+[K]M
M←2 3⍴⍳6 ⋄ K←2 ⋄ 10 20 30+[K]M
// An axis read from a definition's own argument.
∇Z←S K\nZ←+/[K]2 3⍴⍳6\n∇\nS 1
∇Z←S K\nZ←+/[K]2 3⍴⍳6\n∇\nS 2
F←{+/[⍵]2 3⍴⍳6} ⋄ F 1
F←{+/[⍵]2 3⍴⍳6} ⋄ F 2
// An axis the argument does not have is refused where it is read.
M←2 3⍴⍳6 ⋄ K←3 ⋄ +/[K]M
M←2 3⍴⍳6 ⋄ K←0 ⋄ +/[K]M

// --- the axis a ∇ header binds, and χ ------------------------------------
∇Z←SUM[X] B\nZ←+/[X]B\n∇\nSUM[1] 2 3⍴⍳6
∇Z←SUM[X] B\nZ←+/[X]B\n∇\nSUM[2] 2 3⍴⍳6
∇Z←SUM[X] B\nZ←+/[X]B\n∇\nK←1 ⋄ SUM[K] 2 3⍴⍳6
∇Z←SUM[X] B\nZ←+/[X]B\n∇\nSUM[1+1] 2 3⍴⍳6
∇Z←SHOW[X] B\nZ←X\n∇\nSHOW[7] 0
∇Z←SHOW[X] B\nZ←X\n∇\nSHOW[7 8] 0
∇Z←SHOW[X] B\nZ←⍴X\n∇\nSHOW[7 8] 0
∇Z←A JOIN[X] B\nZ←X,A,B\n∇\n1 JOIN[9] 2
F←{⍵+χ} ⋄ F[10]5
F←{⍵+χ} ⋄ F[2×3]5
F←{⍵,χ} ⋄ F[7 8]5
F←{⍵+⍴χ} ⋄ F[7 8]5
F←{⍺+⍵+χ} ⋄ 1 F[10]5
F←{⍵+χ} ⋄ K←4 ⋄ F[K]5
// χ with no axis written is a name with no value.
F←{⍵+χ} ⋄ F 5

// --- indexed assignment inside a larger sentence -------------------------
// The value of `A[i]←v` is the value ASSIGNED, not the array it went into.
A←1 2 3 ⋄ B←A[2]←5 ⋄ B
A←1 2 3 ⋄ B←A[2]←5 ⋄ A
A←1 2 3 ⋄ 2+A[1]←9
A←1 2 3 ⋄ 0+A[1 2]←7 8
A←1 2 3 ⋄ +/A[1]←9
A←1 2 3 ⋄ ⍴,A[2]←5
A←1 2 3 ⋄ C←1 2 3 ⋄ A[1]←C[2]←9 ⋄ A,C
A←2 3⍴⍳6 ⋄ 1+A[1;]←9 9 9
A←2 3⍴⍳6 ⋄ 0+A[1;2]←9
A←2 3⍴⍳6 ⋄ Q←A[;2]←9 9 ⋄ A
A←1 2 3 ⋄ Q←A[1 2]←7 8 ⋄ A
A←1 2 3 ⋄ K←2 ⋄ 0+A[K]←5
A←1 2 3 ⋄ K←2 ⋄ Q←A[K]←5 ⋄ A
// An axis belongs to the call that wrote it: a definition applied inside
// the body does not inherit it.
G←{⍵×2} ⋄ F←{χ+G ⍵} ⋄ F[10]5
// The target of an indexed assignment is a NAME; writing through an
// expression is refused on both sides.
A←1 2 3 ⋄ (A,4)[1]←9
A←1 2 3 ⋄ ((A))[1]←9
// `⊢[M]` is a selection MASK rather than an axis, and it may be computed
// too: a 1 takes the right argument's element, a 0 the left's.
M←1 0 1 ⋄ 1 2 3 ⊢[M] 4 5 6
M←1 0 1 ⋄ ⊢[M] 4 5 6
M←0 0 0 ⋄ 1 2 3 ⊢[M] 4 5 6
