// The nested/mixed DISPLAY itself, byte for byte: a run of adjacent
// characters is text and runs together (no separator), and the gap next
// to any other item widens by how much visual weight that item carries —
// nothing for a scalar, one column per axis for a numeric or boxed
// structure, one column fewer for a character array (a row of characters
// already reads as text on its own, so a character VECTOR costs nothing
// extra and a character MATRIX costs one column). How many `⊂` layers
// wrap the first and the last item sets the vector's own margin.
