// Control structures — `:If`, `:While`, `:Repeat`, `:For`, `:Select` and
// the branch words `:Return`, `:Leave`, `:Continue`. They belong to a
// defined function, not to a dfn, and GNU APL rejects every one of them as
// a syntax error, so there is no `gnu:` column here: this is recorded
// Dyalog ground truth for a future Dyalog dialect, gating nothing.
//
// The function is fixed with `⎕FX` rather than written between two `∇`s.
// The reason is the oracle, not the language: Dyalog is driven here as a
// piped session, where opening the `∇` editor makes it print a `[1]`
// prompt per line and echo the body, so a `∇`-defined tradfn cannot be
// recorded through that channel at all. `⎕FX` takes the same lines as a
// vector of character vectors and fixes the same function. Its result —
// the name — is assigned away so that only the call displays.
@ reference=dyalog
