// Conway's Game of Life, and the nested-array rules it needs.
//
// APL applies a function between the ITEMS of its arguments: an item is
// disclosed on the way in and a result that is not a simple scalar is
// enclosed again on the way into the array being built. `∘.f`, `f/` and
// `f.g` all read that way, which is what makes one line of APL a
// generation of Life. J reads the same operators by cells and leaves its
// boxes shut, so none of this is shared with the J corpus.
//
// The nested DISPLAY is libjay's own approximation (see divergences.txt),
// so the shape, the depth and the enlisted leaves carry the comparison
// wherever the printed planes could hide a difference.

// --- the outer product is between items ----------------------------------
// An enclosed matrix is one item, so the rotate reaches the matrix.
¯1 0 1∘.⌽⊂2 3⍴⍳6
⍴¯1 0 1∘.⌽⊂2 3⍴⍳6
≡¯1 0 1∘.⌽⊂2 3⍴⍳6

(⊂1 2)∘.⌽⊂2 3⍴⍳6
// The items are elements whatever the function's rank, so a whole-argument
// function makes a table rather than one application.

∊1 2∘.,3 4
