// APL's system names: the `⎕`-names a program reads, the two it may also
// set, and the two system functions that answer questions about the names
// in the program itself.
//
// Several lines below record a REFUSAL on both sides — a domain rule, a
// length rule, a name that cannot be assigned. That refusal is the
// behaviour worth pinning, so it is here rather than in the bug register.
//
// A line that fixes a definition assigns `⎕FX`'s answer away (`Q←⎕FX …`):
// a GNU APL session displays every sentence it runs and libjay answers
// with the last one, so a sentence in the middle that has a value would
// differ for that reason alone.
