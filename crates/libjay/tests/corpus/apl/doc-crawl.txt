// element, then depth, then type, then Unicode, then numeric value. `⍋` and
// `⍒` follow those rules; `⌈` and `⌊` do NOT — they stay numeric.

// --- 2.8 Direct Functions (Lambdas) ---------------------------------------
// The manual says a lambda that uses ⍺ but not ⍵ is a SYNTAX ERROR; the
// oracle takes it and treats it as dyadic. The oracle wins.

H←{⍺-⍵} ⋄ 9 H 4

F←{⍺⍶⍵} ⋄ 3(F +)4

// --- 3.3 Known differences from IBM APL2 ----------------------------------
// A number immediately followed by a name is a strand, not a syntax error;
// selective specification of a variable assigned inside its own selector is
// refused; an out-of-domain ⎕IO is refused at the assignment, not later.

((A←2)↑A)←0
