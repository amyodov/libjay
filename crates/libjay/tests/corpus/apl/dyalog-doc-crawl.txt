// A doc crawl: the primitive-function pages of the Dyalog APL Language
// Reference Guide were read one by one, and every behaviour class each page
// states was put to Dyalog itself in expressions of this file's own making.
// The lines here are the ones both sides answered alike; the disagreements
// are tickets, not corpus.

// The pages cover glyphs GNU APL either spells differently or does not have
// (⍸, ⊆, ≢, monadic ≠), so there is no `gnu:` column: this is Dyalog's file
// and the replay holds `Dialect::dyalog()` to it. Answers are kept narrow —
// under the session's 80 columns, since a wider one comes back folded — and
// short, so that a failing row says what broke rather than where.
