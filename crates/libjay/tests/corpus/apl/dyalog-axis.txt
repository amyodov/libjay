// Axis specification where the two APLs part. Dyalog reads `↑[K]` as MIX
// with the item axes placed where K names — a gap between two axes
// included — where GNU APL reads `↑[K]` as FIRST and spells mix `⊃[K]`;
// gives monadic `↓[K]` the SPLIT that GNU APL spells `⊂[K]` and has no
// monadic `↓` for at all; has `⊆[K]` where GNU APL has no such character;
// and pairs the axes of `⌷[K]` and of a SCALAR function with what
// accompanies them in the order K was written, where GNU APL reads K as a
// set and pairs them in ascending order.
//
// Recorded Dyalog ground truth: there is no `gnu:` column here, and the
// Dyalog preset is held to every line.
