// N-wise reduction: the DYADIC case of a `/`-derived function. `n f/ y`
// folds every window of n items; the monadic `f/` is the plain reduce, and
// lives in operators.txt.
//

// ARGUMENT: after a function it is the reduce operator, after a value it is

// `1 1/2 3` is replicate (there is none) — a boolean left argument does not
// make the first one a compress, and a count of 2 does not make the second
// one a window. The disambiguation block below pins that.
