// Where the Dyalog PRESET does not answer what Dyalog answered.
//
// `cargo test -p libjay --test oracle_dyalog` replays every recorded
// `dyalog:` answer under `Dialect::dyalog()` and fails on any difference.
// This file is the whole of the exemption: nothing here is silent, and
// nothing that is not here may differ.
//
// A row is one expression, exactly as the corpus spells it, under a `? `
// note classifying it:
//
//   ? divergence TAG: why libjay keeps answering this way
//   ? gap TAG: what is missing
//
// A DIVERGENCE is a decision — a rule libjay keeps in every dialect, or a
// place the recorded answer is the reference's own edge. A GAP is a
// promise: its tag names a row of docs/status.md's Dyalog table. Closing a
// gap deletes its rows, and the gate then requires them, because a row
// that has stopped differing is a failure of its own: the list shrinks and
// the gate tightens.
//
// The rows are grouped by cause, and the comment above each group says
// what the cause is. Order carries nothing — a row is looked up by its
// sentence, as a snapshot record is — and `@ io=N` sets the index origin a
// row was recorded under, exactly as in a corpus file.

// --- divergence empty-base (5) ------------------------------------------
// An empty base decodes to zeros here and is refused by both references —
// GNU APL agrees about the SHAPE and refuses to print the value, Dyalog
// refuses outright. The rule is libjay's, pinned in
// corpus/apl/divergences.txt, and the same rows appear in fuzz_found.txt.
(⍳0)⊥2 3⍴⍳6
? divergence empty-base: zeros here, a RANK ERROR there
(⍳0)⊥1 2 3
? divergence empty-base: zeros here, a RANK ERROR there
(⍳0)⊥1.5 2.5 ¯0.5
? divergence empty-base: zeros here, a RANK ERROR there
⍴(⍳0)⊥1 2 3
? divergence empty-base: zeros here, a RANK ERROR there
×⍀(÷\\((⍳0)⊥(1.5 2.5 ¯0.5)))
? divergence empty-base: zeros here, a RANK ERROR there

// --- divergence large-count (3) -----------------------------------------
// A rotate amount or a modulus above 2⋆53: libjay reduces the count the
// program wrote, exactly. GNU APL truncates it to 32 bits, Dyalog raises a
// LIMIT ERROR or computes with the float. Pinned in divergences.txt.
9223372036854775806⌽1 2 3
? divergence large-count: the count the program wrote is used here
9223372036854775806|2 3⍴⍳6
? divergence large-count: the count the program wrote is used here
9223372036854775806⌽¯2 0 2
? divergence large-count: the count the program wrote is used here

// --- divergence under-extension (3) -------------------------------------
// `⍢` with a structural operand, which libjay answers and the recorded
// Dyalog refuses. A preset chooses a dialect's rules; it does not withdraw
// an extension libjay ships in every dialect.
(1∘+)⍢⌽ 1 2 3
? divergence under-extension: libjay's ⍢ takes this operand
⌽⍢⊂ 1 2 3
? divergence under-extension: libjay's ⍢ takes this operand
⌽⍢⍉ 2 3⍴⍳6
? divergence under-extension: libjay's ⍢ takes this operand

// --- divergence variant-extension (3) -----------------------------------
// `⍠` with an option Dyalog's variant does not offer. The same rule: the
// preset does not withdraw an extension.
1(=⍠0)1.0000001
? divergence variant-extension: libjay's ⍠ takes this option
'abc'(⍳⍠('IO' 0))'b'
? divergence variant-extension: libjay's ⍠ takes this option
(⍸⍠('IO' 0))0 1 0 1
? divergence variant-extension: libjay's ⍠ takes this option

// --- divergence name-hole (2) -------------------------------------------
// A dfn whose whole body is one identifier, which libjay reads as a `{name}`
// interpolation hole. Braces binding data and never code is a fixed point of
// the embedding; the collision is real APL and has no answer yet.
a←1 ⋄ F←{a←2 ⋄ {a} ⍵} ⋄ (F 0),a
? divergence name-hole: a one-name body is an interpolation hole
a←1 ⋄ F←{{a} ⍵} ⋄ F 0
? divergence name-hole: a one-name body is an interpolation hole

// --- divergence empty-prototype (1) -------------------------------------
// An empty nested array carries no prototype here, so `≡` compares two
// empties equal. Pinned in divergences.txt.
⍬≡0⍴⊂⍬
? divergence empty-prototype: empty prototypes are not compared here

// --- divergence format-character (1) ------------------------------------
// Dyadic `⍕` of a character, which libjay pads as GNU APL does and Dyalog
// refuses. The shipped dialect's reading, kept in both presets.
6 2⍕'a'
? divergence format-character: dyadic ⍕ pads a character here

// --- divergence function-display (1) ------------------------------------
// A derived function displayed where a value belongs: Dyalog shows the
// function's source.
×∘2 5
? divergence function-display: libjay has no display for a function

// --- divergence sequence-value (1) --------------------------------------
// A diamond-separated program has the value of its last sentence and prints
// nothing on the way — Rust's block model, a fixed point of the design.
// Pinned in divergences.txt.
1 2 3⋄4 5
? divergence sequence-value: only the last sentence has a value here

// --- divergence obverse-table (3) ---------------------------------------
// libjay's obverse table is one table over both languages, so a row J's
// `^:_1` reaches is reachable from `⍣¯1` too. Two of these Dyalog does not
// hold: grading is its own inverse there as here only for J, and the third
// is Dyalog's own edge — its inverse of `○` divides by the argument, so a
// zero argument raises DOMAIN ERROR where multiplying by the reciprocal of
// pi answers zero.
⍋⍣¯1⊢2 0 1
? divergence obverse-table: grade is its own obverse here
⍒⍣¯1⊢2 0 1
? divergence obverse-table: grade is its own obverse here
○⍣¯1⊢0
? divergence obverse-table: dividing by zero there, zero here

// --- gap regex (5) ------------------------------------------------------
// `⎕R` and `⎕S`. Pure computation, so the sandbox is no obstacle; they are
// simply not written.
('B' ⎕R 'X'⍠('IC' 1)) 'abcb'
? gap regex: ⎕R and ⎕S are refused by name
('B' ⎕R 'X'⍠('IC' 0)) 'abcb'
? gap regex: ⎕R and ⎕S are refused by name
('b' ⎕R 'X') 'abcb'
? gap regex: ⎕R and ⎕S are refused by name
('b' ⎕S 0) 'abcb'
? gap regex: ⎕R and ⎕S are refused by name
('B' ⎕S 0⍠('IC' 1)) 'abcb'
? gap regex: ⎕R and ⎕S are refused by name

⌈3.5J4.5
? gap complex-floor: the complex floor is taken per part here

// --- gap obverse-of-bond (2) --------------------------------------------
// The obverse of a bound verb, and of an operand known only at run time: the
// obverse table reads the verb tree, and neither is in it.
UNDER←{⍵⍵⍣¯1⊢(⍵⍵ ⍺) ⍺⍺ (⍵⍵ ⍵)} ⋄ 1 2 3 (+UNDER ⌽) 10 20 30
? gap obverse-of-bond: the obverse table does not hold this verb
(2∘↑)⍣¯1⊢1 2
? gap obverse-of-bond: the obverse table does not hold this verb

// --- gap operand-parens (2) ---------------------------------------------
// An operand in PARENTHESES to the right of an operator, which the operator
// folder reaches before the `)` has closed. A parser ordering gap, not a
// missing meaning.
HALF←{⍺⍺ ⍵⍵ ⍵} ⋄ (⌽HALF (2∘↑)) 1 2 3 4
? gap operand-parens: the operand's ) has not closed yet
2 =⍥(2∘|) 4
? gap operand-parens: the operand's ) has not closed yet

⍴(1 1 1⍴5)+1 1⍴3
? gap singleton-rank: the first argument's rank wins here

F←{⍺←⊢ ⋄ ⍺ ⍵} 7

// --- gap stencil-empty (1) ----------------------------------------------
// `⌺` over an empty, which Dyalog refuses.
{+/,⍵}⌺3⊢⍬
? gap stencil-empty: ⌺ over an empty answers here

// --- gap axis-strict (2) ------------------------------------------------
// Two places Dyalog refuses an axis the APL2 line accepts. A SCALAR
// function there wants its smaller argument to be exactly as long as the
// axis, so a scalar has nothing to line up and is a LENGTH ERROR, where
// GNU APL spreads it as it would without an axis at all. And `⍪` there
// takes no axis whatever, while GNU APL reads one on either catenate
// glyph. Both are the preset being more permissive than Dyalog, and each
// needs a rule of its own to close.
1+[1]2 3⍴⍳6
? gap axis-strict: a scalar spreads under an axis here, a LENGTH ERROR there
⍪[1]2 3⍴⍳6
? gap axis-strict: ⍪ reads an axis here, a SYNTAX ERROR there
