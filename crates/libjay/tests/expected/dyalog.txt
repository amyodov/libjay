// Where the Dyalog PRESET does not answer what Dyalog answered.
//
// `cargo test -p libjay --test oracle_dyalog` replays every recorded
// `dyalog:` answer under `Dialect::dyalog()` and fails on any difference.
// This file is the whole of the exemption: nothing here is silent, and
// nothing that is not here may differ.
//
// A row is one expression, exactly as the corpus spells it, under a `? `
// note classifying it:
//
//   ? divergence TAG: why libjay keeps answering this way
//   ? gap TAG: what is missing
//
// A DIVERGENCE is a decision — a rule libjay keeps in every dialect, or a
// place the recorded answer is the reference's own edge. A GAP is a
// promise: its tag names a row of docs/status.md's Dyalog table. Closing a
// gap deletes its rows, and the gate then requires them, because a row
// that has stopped differing is a failure of its own: the list shrinks and
// the gate tightens.
//
// The rows are grouped by cause, and the comment above each group says
// what the cause is. Order carries nothing — a row is looked up by its
// sentence, as a snapshot record is — and `@ io=N` sets the index origin a
// row was recorded under, exactly as in a corpus file.

// --- divergence empty-base (5) ------------------------------------------
// An empty base decodes to zeros here and is refused by both references —
// GNU APL agrees about the SHAPE and refuses to print the value, Dyalog
// refuses outright. The rule is libjay's, pinned in
// corpus/apl/divergences.txt, and the same rows appear in fuzz_found.txt.
(⍳0)⊥2 3⍴⍳6
? divergence empty-base: zeros here, a RANK ERROR there
(⍳0)⊥1 2 3
? divergence empty-base: zeros here, a RANK ERROR there
(⍳0)⊥1.5 2.5 ¯0.5
? divergence empty-base: zeros here, a RANK ERROR there
⍴(⍳0)⊥1 2 3
? divergence empty-base: zeros here, a RANK ERROR there
×⍀(÷\\((⍳0)⊥(1.5 2.5 ¯0.5)))
? divergence empty-base: zeros here, a RANK ERROR there
