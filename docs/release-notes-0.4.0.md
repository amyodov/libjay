This release finishes the GNU APL push: the primitive vocabulary of GNU APL is complete, verified expression by expression against the interpreter itself. The remaining gaps are workspace machinery and run-time text compilation, each named in docs/coverage.md with the reason it waits.

The largest addition is the axis specification, `f[K]`, for every function that reads one. Catenate and laminate (`x,[k]y`, `x,[k.5]y`), ravel over runs of axes, take and drop per axis, index (`x⌷[K]y`), enclose and partition (`⊂[K]`, `x⊆[k]y`), first and mix (`↑[K]`, `⊃[K]`), and the scalar functions dyadically (`1 2+[1]2 3⍴⍳6`) — all verified against both GNU APL and Dyalog, under both index origins. One new dialect setting, `axis_order`, captures the one place the two APL lines pair an axis list differently.

Operands the program computes come with it: a `⍣` or `^:` count, an `f[K]` axis, and an array operand may now be a name or an expression, read where the derived function is applied rather than while the program compiles — so a definition's own argument can decide which axis to sum. A `∇` header may name an axis of its own, and a `{…}` reads it as `χ`. Indexed assignment may stand inside a larger sentence, and its value is the value assigned — which also fixes a wrong answer, since it used to yield the whole amended array.

The `⎕`-system names arrived: `⎕AV`, `⎕PP` and `⎕RL` readable and settable at run time, `⎕NC`, `⎕CR` in its monadic and seven dyadic conversions, `⎕CC`'s glyph repertoires, `⎕EM`/`⎕ET`/`⎕LX`, and the polynomial arithmetic `⌹[8]` and `⌹[9]`. The ones libjay will not answer now say which kind of thing they are — an interpreter's build table, a shared-variable offer the sandbox keeps closed — instead of naming a queue position.

A certification sweep of 110,000 generated expressions ran against the GNU APL interpreter before this release: zero panics, zero internal errors, and every disagreement classified as a fix, a pinned divergence with reasoning, or a registered gap. The sweep's catches are in this release: enlist `∊` failed on any empty leaf of one type beside a value of another; membership compared two integers as doubles, so any two past 2⋆53 were equal to it; scalar-function pervasion of a value thousands of boxes deep took the process down, and now runs on a work stack.

Two behaviours moved to match the reference where libjay had been the permissive one: index brackets bind to the value written immediately before them, so `1 2 3[2]` is a rank error rather than an index into the strand, and `⌹` of rank 3 or more is a rank error on either side. The gamma function reached the complex plane — `!2j1` answers in both languages, digit for digit what the references print.

Nothing in the public API is displaced; `Dialect.axis_order` and the new system names are additions beside the existing surface.
